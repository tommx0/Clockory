Verarbeitung von Daten

Clockory speichert und verarbeitet alle von der nutzenden Person in der App eingegebenen Daten ausschließlich lokal auf dem verwendeten Gerät.

Es werden keine personenbezogenen Daten an externe Server, Cloud-Dienste, Dienstleister oder sonstige Dritte übertragen. Eine Weitergabe oder ein Verkauf von Daten findet nicht statt.

Clockory verwendet kein Tracking, keine Werbung und keine Analyse des Nutzungsverhaltens. Es werden keine Analyse-, Werbe- oder Crash-Reporting-Dienste eingesetzt.

Clockory bietet keine Übertragung oder Synchronisierung der eingegebenen Daten über iCloud oder andere Cloud-Dienste an.

Speicherung und Löschung

Die Daten werden ausschließlich lokal auf dem Gerät gespeichert. Da keine Daten auf Servern von Clockory gespeichert werden, kann Thomas Marx auf diese lokalen Daten nicht zugreifen oder sie auf Anfrage remote löschen.

Die nutzende Person ist für den Schutz des Geräts und der lokal gespeicherten Daten verantwortlich. Die lokal gespeicherten Daten können über die von Clockory bereitgestellten Funktionen gelöscht werden. Eine Deinstallation der App kann ebenfalls lokal gespeicherte App-Daten entfernen, soweit dies vom Betriebssystem vorgesehen ist.

Data processing

Clockory stores and processes all data entered by the user exclusively on the device used to run the app.

Clockory does not provide transmission or synchronization of entered data through iCloud or any other cloud service.

Users are responsible for protecting their device and locally stored data. Local data can be deleted using the functions provided by Clockory. Uninstalling the app may also remove locally stored app data, as provided by the operating system.
